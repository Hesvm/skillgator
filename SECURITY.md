# Security Policy

## Supported Versions
Skillgator is currently in active development. Security updates are applied to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability
Skillgator runs locally and accesses read-only filesystem paths. If you discover a security vulnerability, please open a GitHub Security Advisory or report it directly via GitHub issues.
